\section{事前登録が働いた記録}

以下は、事前に予測を文章として固定していなければ
事後的な解釈に流れていたと考えられる箇所である。

\begin{enumerate}[label=(\arabic*)]
\item \textbf{上限制手数料の消滅。}
族5において上限制が99.7\%消滅している事実は、
可測性仮説の傍証として解釈することが可能であった。
実際には上限制の価格水準が一桁低いだけで、可測性とは無関係である。

\item \textbf{$\CCC$ と売上高の同期負相関。}
45業種中31業種で負の相関（$p=0.008$）が得られた。
これを「$\CCC$ は景気指標として機能する」と読むことができたが、
分母効果と区別できていない。

\item \textbf{大企業の与信ポジション。}
$\mathrm{DSO}-\mathrm{DPO}$ が大企業で大きいことを
「大企業が取引先を支えている」と解釈しえた。
実際には予測Fが符号ごと棄却された結果である。
\end{enumerate}

第\ref{sec:narrative}節で他者の記述について述べた事後的物語化は、
筆者自身の解釈にも同様に生じる。

\section{可逆性の検討と訂正}

不可逆性の観点から枠組みを見直し、既存理論との照合を行った。
結果として一件の訂正と二件の追加が生じた。

\textbf{訂正。} 注\ref{rem:rho-endogenous}において、
$\rho$ が内生的になる機構を「相関の低い対象が枯渇する」と記述していた。
\cite{wagner2010} によれば正しい機構は異なる。
集約の対象が減るのではなく、\textbf{集約という行為そのものが集約者間の相関を生む}。
二主体が二リスクを等分に持てば、各主体は個別には安全になるが両者は完全に相関する。

\textbf{追加。} $\Phi$ の切り替え費用（注\ref{rem:switching-cost}）と
集約の社会的最適性（注\ref{rem:pooling-social}）を記録した。
前者は不可逆投資の理論、後者はシステミックリスクの研究に対応がある。

なお可逆性を費用の大小で分類する枠組み自体は、
不可逆投資の理論が既に持つものであり、本稿の寄与ではない。
決定が不可逆であるのは物理的に取り消せないためではなく
取り消しの費用が高いためである、という定式化は \cite{dixit1994} の系譜に属する。

$\Phi$ が所与で顧客が一社に集中する一人事業、という見方である。

労働基準法が第\ref{sec:dof}節の六自由度のうち五つを制約しており、
$\phi_{\mathrm{prod}}$ と $\phi_{\mathrm{cog}}$ には対応物がない。

\section{操作化の補充と未解決一覧の整理}

第\ref{ch:design}章の五段階に照らして各項目を分類したところ、
\textbf{段階1（操作化）で止まっている項目が未解決の一覧に登録されていない}ことが判明した。
段階1の不備はデータ取得を要さず定義で埋まるにもかかわらず、
一覧は測定とアクセスの問題に偏っていた。

第13段階で次を行った。

\begin{enumerate}[label=(\arabic*)]
\item \textbf{可用性を式として書いた}（定義\ref{def:availability}）。
従来は「拘束を消費する」と述べるにとどまり不等式の形を持たなかった。
容量制約が履行の総量に上限を課すのに対し、
可用性は連続して応答できない区間の長さに上限を課す。次元はともに時間である。

\item \textbf{無人化の程度が定義できない理由を特定した}（注\ref{rem:automation-rate-illposed}）。
従来は「$\delta$ の単位が存在しない」と記していたが、
$\delta$ は評価写像により貨幣単位を持つ。
正しくは、$v$ が測るのは価値であって手間ではなく、
応答の側で測ろうとすれば $\Omega\setminus\hat\Omega$ に測度が定義されない。
\textbf{障害は単位の不在ではなく測度の不在であり、定義の精密化では解消しない。}

\item \textbf{類型への割り当て規則を定めた}（第\ref{sec:type-assignment}節）。
カタログを実証に用いるには観測された $\Phi$ をどの類型に割り当てるかの規則が要るが、
これを持たなかった。族の判定条件は排他的でないため順序を固定した。
順序の選択に演繹的な根拠はなく規約であるから、事前に固定する必要がある
（注\ref{rem:assignment-order-dependence}）。

\item \textbf{第\ref{part:unmanned}章に限界節を置いた}（第\ref{sec:unmanned-limits}節）。
演繹の章のうち同章のみが限界節を持たず、
その限界は第\ref{ch:platformfee}章に書かれていた。
理論側の限界を同章へ移し、実証側の限界は第\ref{ch:platformfee}章に残した。

\item \textbf{未解決の問題を12項目から21項目に整理し直した。}
各章の限界節と断念の記録に、一覧に反映されていない項目が9件あった。
うち6件は\textbf{いずれの障害にも該当せず、着手していないだけ}であったため、
「障害を持たないもの」として小節を分けた。
優先順位の表も、着手できるものと前進しないものに分けた。
\end{enumerate}

これにより第\ref{ch:conclusion}章の締めが変わった。
従来は「公表データの取得のみで前進できる項目は残っていない」としていたが、
障害を持たない項目が六件ある。

\section{実証設計の前置き}

第\ref{part:obstacles}章は、四分類を調査設計の前段に置くべきであると記録していた。
第\ref{part:method}部が標本の選択バイアスを扱う一方で、
「そもそも検証が可能か」を判定する手続きを持っていなかったためである。

第12段階でこれを第\ref{ch:design}章として実行した。
ただし四分類そのものは前置きしていない。
分類は実証を経て六つに拡張された結果であり、
前置きすればまだ得られていない知見を先に置くことになる。
\textbf{前に出したのは確認すべき段階のみであり、
通過できなかった原因の分類は第\ref{part:obstacles}章に残した}（注\ref{rem:taxonomy-placement}）。

あわせて、照合と検証の区別を規律として明示した（第\ref{sec:comparison-vs-test}節）。
本稿には第\ref{ch:solo}章の族3の照合など、事前登録によらない整合確認が複数あるが、
それらの位置づけを述べた箇所がなかった。
各章が個別に「事後的な照合であり因果を示すものではない」と断るにとどまっていた。
規律が要るのは、照合が母集団の宣言を要さないため
段階2と3を飛ばして成立してしまうからである（注\ref{rem:comparison-skips-stages}）。

\section{件数の訂正}

第\ref{part:catalog}部のカタログを第1段階から一貫して「27類型」と記していたが、

\section{検討したが本文に採らなかったもの}

第9段階で第\ref{ch:protocol}章を書くにあたり、
当初はこれを新規の寄与として提示する構成を検討した。
文献を確認した結果、担保制約による調達の制限、
資産を持たない主体の排除、識別子と主体の乖離のいずれにも
既存の対応があることが判明したため、
新規性を主張しない形に改め、付録\ref{app:priorwork}に対応表を追加した
（注\ref{rem:collateral-priorwork}）。

本章を残したのは、第\ref{part:theory}部の理論が
具体的な条件の下でどう機能するかを示す位置に、
第\ref{sec:info}章の $\mathcal{G}$ を動かす例が欠けていたためである。
第\ref{ch:solo}章および第\ref{part:unmanned}章と同じ役割による。

\section{構成の変更}

内容の訂正とは別に、構成を二度変更した。

\begin{enumerate}[label=(\arabic*)]
\item 検討の時系列順から、理論・類型・方法・実証・総括の論理順へ。
\item 制約下の演繹（第\ref{ch:solo}章、第\ref{part:unmanned}章）を
独立した「応用」部から第\ref{part:catalog}部へ移動。
応用が正当化されるのは理論が実証を経た後であり、本稿の実証は完結していないため。
\end{enumerate}

第二の変更に伴い、64件の参照不整合（部と章の取り違え）と
2件の論理逆転（後続の章を過去形で参照）を修正した。
