# データ一式

本稿の実証に用いたデータと処理。すべて公開統計から取得したもの。

```
raw/        取得したままのデータ
derived/    パースして JSON 化した中間データ
scripts/    分析の処理
```

---

## raw/hojin — 財務省「法人企業統計調査」

e-Stat 統計表 ID `0003060791`。項目を選んで CSV でダウンロードしたもの。
文字コードは CP932。

| ファイル | 内容 | 用途 |
|---|---|---|
| `A_gyoshu_jikeiretsu.csv` | 全62業種・全規模・2000〜2024年度。売掛金、買掛金、受取手形、支払手形、製品又は商品、売上高 | $\CCC$ の時系列、シフト・シェア分解 |
| `B_kibo_dammen.csv` | 主要業種・全16規模階層・2015〜2024年度。同上 | 規模階層別の $\kappa$ |
| `C_jinkenhi.csv` | 役員給与、役員賞与、従業員給与、従業員賞与 | 命題18.8（役員報酬） |
| `E_genka_setsubi.csv` | 減価償却費、有形固定資産、無形固定資産、土地、建設仮勘定、資産合計、棚卸資産 | $g^\star$ の分子（$d$ と $I$） |
| `A_old_predE.csv` | 予測E検証時の初期取得。`A_gyoshu` の部分集合 | 参考 |
| `B_old_predF.csv` | 予測F検証時の初期取得 | 参考 |

**注意。** 業種分類は2008年度に改定されており、2000年度時点は33業種、
2024年度は45業種。時系列を扱うときは共通業種に限定すること
（`scripts/shift.py` を参照）。

## raw/chusho — 中小企業庁「中小企業実態基本調査」

標本約11万社。**法人企業と個人企業が同一の従業者規模区分に並ぶ**唯一の統計。

| ファイル | 内容 |
|---|---|
| `r07_02_shisan_fusai.xlsx` | 資産及び負債・純資産（**法人企業のみ**） |
| `r07_03_uriage_hiyo.xlsx` | 売上高及び営業費用（個人企業を含む） |
| `r07_06_setsubi_lease.xlsx` | 設備投資とリースの状況（個人企業を含む） |
| `timeseries_r02-r07.zip` | 上記3表の令和2〜7年確報（18ファイル） |

**個人事業主の資産・負債は集計されない。** 調査票甲には個人事業者用が
存在するが、公表される集計表は法人企業のみ。これが未解決問題(10)の障害である。

令和6年確報までは設備投資の表が `04_1`、令和7年から `06_1` に変わっている。

Excel の構造は年度で異なる。項目名列の位置が令和2・3年と令和4年以降でずれるため、
`scripts/panel2.py` は自動検出している。

## raw/jinzai — 厚生労働省「人材サービス総合サイト」

予測X（手数料実績率と離職率の相関）に用いた個社データ。
**Python のリストとして構造化済み**で、元の HTML は保存していない。

| ファイル | 職種 | 社数 |
|---|---|---|
| `nurse.py` | 看護師、准看護師 | 108 |
| `doctor.py` | 医師 | 119 |
| `care.py` | 施設介護の職業 | 103 |
| `hoiku.py` | 保育士 | 70 |

各行の形式。

```python
("許可番号", 無期就職者数, 手数料率, "p|y", 離職率, 認定, [優良])
#  p = パーセント表示、y = 金額表示
```

**取得条件。** 都道府県=東京、許可番号=13-ユ、離職率=0〜100%。
詳細検索で職種を指定すると、結果一覧に手数料実績率と離職率が同時に表示される。
指定できる職種は医療・介護・保育分野の9つに限られる。

**再取得する場合の注意。** 許可番号を含む URL を直接指定すると、
存在しない番号に対して直前の取得結果が返ることがある。

### search/ — 詳細検索の結果一覧（予測Y 用）

全国・四職種を2026年9月3日に取得した生のテキスト。**扱いの注意は同ディレクトリの README。**
上の `*.py` と違い整形していないため、次の二点に注意する。

- **行は事業所単位だが、値は企業単位**が全事業所に複製されている。名寄せが要る
- **複写時に行が脱落している**（1.7〜11.2%）

`scripts/parse_jinzai.py` が名寄せして `derived/jinzai_firms.json` を作る。
検索画面から遷移すること。

## derived/ — 中間データ

`raw/hojin` の CSV をパースして JSON 化したもの。
`scripts/parse.py` が生成する。

| ファイル | 対応 |
|---|---|
| `A.json` | `A_gyoshu_jikeiretsu.csv` |
| `B.json` | `B_kibo_dammen.csv` |
| `C.json` | `C_jinkenhi.csv` |
| `Am.json`, `Bm.json` | 売上原価・販管費・営業利益（別途取得分） |
| `E.json` | `E_genka_setsubi.csv` |

各要素は `{"ind": 業種名, "size": 規模, "year": 年度, ...}` の辞書。

## scripts/ — 分析の処理

| スクリプト | 内容 | 対応する箇所 |
|---|---|---|
| `parse.py` | raw/hojin の CSV → derived/*.json（A・B・Am・Bm・C・E） | ― |
| `ccc.py` | $\CCC$ の算出 | 第20章 |
| `e1.py` | $\CCC$ と売上高のラグ相関 | 予測E |
| `f2.py` | 規模別 $\mathrm{DSO}-\mathrm{DPO}$ | 予測F |
| `gstar.py`〜`gstar4.py` | $g^\star$ の算出（段階的に精密化） | 系7.3、第18.5節 |
| `decomp.py`, `decomp2.py` | 粗利率と販管費率の分解 | 命題18.8 |
| `adj.py` | 人件費を原価に戻した比較 | 同上 |
| `shift.py` | シフト・シェア分解 | 予測M |
| `comp.py` | DSO/DIO/DPO の成分分解 | 第20.8節 |
| `dso.py` | DSO の業種別分解 | 同上 |
| `elast.py` | 運転資本の売上弾力性 | 予測N |
| `lag.py` | 分布ラグ推定 | 予測O、P |
| `migration.py`, `ind_stab.py` | 推定の安定性 | 注18.5 |
| `sme.py`, `sme2.py`, `panel2.py` | 中小企業実態基本調査 | 予測U |
| `jinzai_test.py` | 手数料率と離職率の相関 | 予測X |
| `inv.py` | 棚卸資産の範囲が $\CCC$ と $\beta$ に与える影響 | 第20.10節 |
| `parse_jinzai.py` | 詳細検索の結果一覧を名寄せして読む | 第17.5節 |
| `predY.py` | 予測Y の検定 | 同上 |

実行例。

**必要なもの。** Python 3 の標準ライブラリのみで動く。
ただし中小企業実態基本調査の Excel を読む 4 本
（`sme.py`、`sme2.py`、`panel.py`、`panel2.py`）は `openpyxl` を要する。
同調査の時系列を使う場合は、先に zip を展開しておく。

```bash
pip install openpyxl
cd raw/chusho/extracted && unzip ../timeseries_r02-r07.zip
```

```bash
cd scripts
python3 parse.py       # raw/hojin から derived/*.json を作る（最初に必ず実行）
python3 gstar4.py      # g* を算出
python3 jinzai_test.py # 予測X の検定
```

**パスは実行時のディレクトリに依存する。** 元は `/home/claude/ccc/` で
動かしていたため、`json.load(open("A.json"))` のように相対で書かれている。
移行先で `derived/` を参照するよう直す必要がある。

## 再取得の手順

いずれも公開されており、同じ条件で再取得できる。

**法人企業統計。** e-Stat の統計表 ID `0003060791` から、
調査項目・業種・規模・年を選んでダウンロード。上限は10万セル。

**中小企業実態基本調査。** e-Stat の `toukei=00553010`、
`tstat=000001019842`。年次ごとの確報の下に統計表が78件前後ある。

**人材サービス総合サイト。** `jinzai.hellowork.mhlw.go.jp` の
職業紹介事業所検索。詳細条件で職種と離職率を指定する。

**日本資金決済業協会「発行事業実態調査統計」。**
族2の $\kappa$ に用いたが、本一式には含めていない（PDF から手で転記した）。
