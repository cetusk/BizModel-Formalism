機械可読の配布形式が用意されていないため、この形でしか取得できない。

**このテキストは git に入れていない。** 事業所ごとの届出内容そのものであり、
本稿は解析の入力として用いるが、集合を複製して再配布はしない
（リポジトリ README「データの取り扱い」）。
残してあるのは許可番号の一覧 `../permits.tsv` だけで、届出の値は含まない。

## 再取得の手順

自動取得の口はない。**一覧は手作業で複写する。** 次の順で行う。

1. `https://jinzai.hellowork.mhlw.go.jp/JinzaiWeb/GICB101010.do?action=transition&screenId=GICB101010&params=1`
   から職業紹介事業所の詳細検索を開く
2. 条件は**都道府県=全国、離職率=0〜100％、職種のみ指定**。他は既定のまま
3. 職種は「1.医師」「4.看護師、准看護師」「7.施設介護の職業」「9.保育士」の四つを順に
4. 結果一覧を全ページ選択して複写し、`{職種}_全国.txt` として UTF-8 で保存する
5. 冒頭に「検索結果 N 件」の行を残す。**これが取りこぼしの検査に要る**

複写したら必ず件数を検算する。データ行（タブ7個以上の行）の本数が
宣言件数と一致しなければ、複写ではなく抽出の正規表現を疑うこと。

```bash
cd data/scripts
python3 parse_jinzai.py ../raw/jinzai/search/*.txt
```

**値だけなら手作業を経ずに再現できる。** `../permits.tsv` の許可番号から
`fetch_jinzai_detail.py` で詳細ページを取れば、手数料実績率と離職率、
就職者数が職種別に得られる（20社26行で一覧と完全に一致することを確認済み）。
手作業が要るのは、その許可番号の一覧そのものを作り直す場合だけである。

## 形式

1レコードが4行。認定表示があれば行が増える。レコード間に空行が入る。

| 行 | 内容 |
|---|---|
| 1 | 許可・受理番号 |
| 2 | 許可年月日 TAB 事業主氏名 |
| 3 | 事業所名称 TAB 事業所所在地 |
| 4 | 電話 TAB 就職者(4ヶ月以上有期及び無期) TAB うち無期 TAB 4ヶ月未満有期(人日) TAB 離職者数(無期・6ヶ月以内) TAB 職種 TAB 手数料実績率 TAB 離職率 TAB 備考 |

## 扱う際の注意

**行は事業所単位だが、就職者数・離職率・手数料は許可番号（企業）単位の値が
全事業所に複製されている。** 名寄せしないと支店の多い企業が重複して効く。
医師では株式会社パソナ 1 社が 471 行中 134 行を占める。

**表示される離職率は、同じ行の就職者数・離職者数から計算できない。**
医師では一致するのが 471 行中 115 行のみで、両者は期間が異なる。
離職率はサイト側の集計値として扱う。

**複写による脱落はない。** データ行（タブ7個以上の行）の本数は
検索結果の宣言件数と完全に一致する。

| 職種 | 検索結果 | データ行 |
|---|---|---|
| 施設介護の職業 | 1,075 | 1,075 |
| 保育士 | 552 | 552 |
| 医師 | 479 | 479 |
| 看護師、准看護師 | 1,322 | 1,322 |

**許可番号の記号は三種ある。** ユ（有料）3,221 件、ム（無料職業紹介所）200 件、特 7 件。
`[ユフ]` に限って抽出すると無料職業紹介所を落とす。
当初これを複写の脱落と誤認し、最大 11.2% が失われたと記録していた。
**抽出漏れが出たら、まずデータ行の本数と宣言件数を突き合わせること。**

## html/ — 結果一覧をページごと保存したもの

同じ検索の1ページ目（20行）を、4職種についてブラウザの「名前を付けて保存」で
取得したもの。テキストの複写では失われる **`detkey_Detail`** を含む。

```
html/{職種}_全国/{職種}_全国.html        本体
html/{職種}_全国/{職種}_全国_files/      画像・CSS・JS（解析には使わない）
```

**詳細ページの鍵はここにしかない。** 事業所詳細の URL は

```
GICB102030.do?screenId=GICB102030&action=detail&detkey_Detail={許可番号}%2C{連番}
```

で、連番は6桁に左詰めで空白詰めする（`1+++++`）。
**連番は 0 か 1 の二値である。** 4職種の1ページ目に現れる78個の鍵で
1 が 64、0 が 14。両方を持つ許可番号もある（13-ユ-080509 の本社と大阪営業所）。

1 しか試さないと3割前後が「サーバーでエラーが発生しました」を返す。
取れる社と取れない社は事業所数とも種別とも相関しないため、
**片方だけで打ち切ると非ランダムな欠測になる。** 両方を試すこと。
連番が違っても就職者数・手数料・離職率は同じ値が返る（企業単位の値であるため）。

cd data/scripts
